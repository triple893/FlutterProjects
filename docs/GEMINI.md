## 1. プロジェクトビジョン
**「AIと共に、アイデアを即座に形に。AndroidとiOS、両方の世界で輝く、革新的なモバイルアプリケーションを創造する。」**
このプロジェクトは、Flutterのクロスプラットフォーム能力と、AIによる開発支援を最大限に活用し、思いついたアイデアを驚くべきスピードで、高品質なモバイルアプリとして実現することを目指します。

## 2. アプリケーションの基本設計

### 2.1. コアコンセプト：クラウドネイティブなアプリ開発基盤
- **開発環境:** 丼ちゃんのPCに依存しない、完全にクラウド化された開発環境（GitHub Codespaces）を構築します。
- **自動化:** `.devcontainer.json` を活用し、誰が、いつ、どこで開発を始めても、ワンクリックで同じFlutter開発環境が自動的にセットアップされる仕組みを実現します。
- **プレビュー:** 開発中のアプリケーションは、Webブラウザ上でリアルタイムにプレビューし、高速な開発サイクルを実現します。

### 2.2. 技術スタック
- **フレームワーク:** Flutter
- **言語:** Dart
- **開発環境:** GitHub Codespaces
- **CI/CD (将来的には):** GitHub Actions

## 4. 主要ファイルパス

パスはすべてリポジトリルートからの相対パスです。開発はGitHub Codespaces上で行うため、ローカルPC固有のパスは使用しません。

- `docs/GEMINI.md`: このファイル
- `docs/PROGRESS.md`: 詳細な進捗管理
- `docs/DECISION_LOG.md`: プロジェクト意思決定ログ
- `docs/README.md`: プロジェクトの概要と使い方
- `docs/PROJECT_STATUS_REPORT.md`: プロジェクトのステータスレポート
- `README.md`: リポジトリのトップページ（技術スタック・開発コマンド）
- `.devcontainer/devcontainer.json`: 開発環境の設計図
- `.github/workflows/ci.yml`: CI（解析・テスト・Webビルド）の定義
- `lib/main.dart`: アプリケーションのエントリポイント
- `test/widget_test.dart`: ウィジェットテスト
- `pubspec.yaml`: 依存パッケージとアプリのメタデータ
