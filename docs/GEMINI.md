## 2. アプリケーションの基本設計

### 2.1. コアコンセプト：クラウドネイティブなアプリ開発基盤
- **開発環境:** 丼ちゃんのPCに依存しない、完全にクラウド化された開発環境（GitHub Codespaces）を構築します。
- **自動化:** `.devcontainer.json` を活用し、誰が、いつ、どこで開発を始めても、ワンクリックで同じFlutter開発環境が自動的にセットアップされる仕組みを実現します。
- **プレビュー:** 開発中のアプリケーションは、Webブラウザ上でリアルタイムにプレビューし、高速な開発サイクルを実現します。

### 2.2. 技術スタック
- **フレームワーク:** Flutter
- **言語:** Dart
- **開発環境:** GitHub Codespaces
- **CI/CD (将来的には):** GitHub Actions
