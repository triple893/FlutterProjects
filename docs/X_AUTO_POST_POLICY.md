# X自動投稿ポリシー — 自分発の新規投稿

## 0. 適用範囲

X自動投稿のうち、**自分自身の新規投稿**のみを対象とする。
返信、他人へのリプライ、リポストは対象外で、従来のルールのまま。

このファイルはそのまま自動投稿タスクのプロンプトとして差し替えて使うことを想定している。

## 1. 投稿枠は2種類

| 枠 | 中身 | 比率 |
|---|---|---|
| A | AIニュースの引用リプライ | おおよそ半分 |
| B | 自由投稿 | おおよそ半分 |

比率は日単位で厳密に守るものではなく、ならして半々になっていればよい。
枠Aのネタが無い日は枠Aを出さない。枠Bのネタが無い日は枠Bを出さない。両方無い日は**投稿しない**。

## 2. 枠A — ニュース引用リプライ

### 拾う対象

Anthropic / OpenAI / Google（DeepMind含む）の発表。
モデルのリリース、機能追加、料金・レート制限の変更、開発者向けツールの更新など。

### 選定基準

**「自分の環境で今ハマっている問題を埋めるか」だけで選ぶ。**

業界的に大きいニュースでも、自分の手元の詰まりに効かないなら拾わない。
逆に地味な変更でも、今の詰まりが解消するなら拾う。この基準以外で選ばない。

### 形式

- 引用リプライ（quote post）で出す。単独の新規投稿としてニュースを紹介しない。
- **感想は一言**。引用元を読めば分かることは書かない。
- ニュースの要約を書かない。「〜が発表されたらしい」「〜とのこと」のような伝聞の要約は禁止。
- 書くのは「自分にとって何が変わるか」。
- 1投稿につき1ニュース。まとめない。

```
悪い例: 「Anthropicが新しいモデルを発表したとのこと。コンテキスト長が拡大され、
        価格も改定されたようです。これは開発者にとって大きな変化になりそう。」
良い例: 「これで例の詰まりが一発で消える。」
```

## 3. 枠B — 自由投稿

### 書き方のルールは設けない

文体、構成、長さ、オチの付け方に指定はない。**内容が面白いかどうかだけが条件。**
テンプレートに寄せず、その時の話に合った書き方をする。

### 書かないもの

- 自分の開発環境の紹介、構成の説明、環境自慢
- 「今日は〜をやりました」形式の日報
- 具体例を伴わない抽象論・一般論

### ネタが無い日

**投稿しない。** 無理に埋めない。件数のために薄い投稿を出すことを禁止する。

## 4. 書式（両枠共通・これだけ守る）

- **改行しない。1投稿 = 1段落。** 箇条書き、見出し、区切り線、行頭の記号を使わない。
- 定型の書き出し・締め文句を使わない。
- 上記以外の文体ルールは設けない。

## 5. 旧ルールからの変更点

| 項目 | 旧 | 新 |
|---|---|---|
| 改行 | 読みやすさのため段落を分けていた | 1段落に統一、改行なし |
| 文体 | 書き方のテンプレートあり | 指定なし（内容重視） |
| 自分の環境の話 | 主要な題材 | 禁止 |
| 最新ニュース | 扱わない | 引用リプライで扱う（全体の約半分） |
| ネタ切れ時 | 環境の話などで埋める | 投稿しない |

## 6. 未決定（必要になったら決める）

- ハッシュタグと絵文字の扱い
- 投稿時刻と1日あたりの上限本数
- 英語ニュースを引用する際に日本語で書くか
