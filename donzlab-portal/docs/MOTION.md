# 動きの法則 — Laws of Motion

城の動きは飾りではなく、仕組みと状態を伝える言葉。どの動きにも理由がある。理由のない動きは入れない。
見本は Claude Design のキャンバス「動きの法則」ボードにある。

| 法則 | 動き | 理由 | 実装 |
| --- | --- | --- | --- |
| 一　因果 | 回路の光は線の向きに沿って、外から中枢へ流れる。中枢の朱は 1 分に 60 回の心拍 | ラボの成果が城に集まる仕組みを見せる。城が動いていることを伝える | `src/pages/index.astro`（`.current` / `.heart`）、`WorldArt` の `circuit` |
| 二　物理 | 弦は弾いた瞬間がいちばん大きく揺れ、振幅が小さくなって止まる。入場時に一度だけ鳴る | 本物の弦と同じ減衰で、触った手応えになる | `WorldArt` の `strings`、ラボページの「弦を弾く」（`data-pluck`） |
| 三　状態 | 脈打つのは「稼働中」だけ。開発中は灯るだけ、準備中は輪郭だけ | 説明を読まなくても、動きで状態がわかる | `src/components/Status.astro` |
| 四　門 | 門に触れると金の紋が描き起こされ、漢数字が朱に変わる。くぐるとカードがラボの世界へつながる | ページ移動を「門をくぐる」体験にする | `GateMotif` / `LabCard`、View Transitions（`view-transition-name: gate-*`） |
| 五　順序 | 小見出し → 見出し → 説明 → ボタンの順に、少しずつ遅れて現れる | 目が読む順に合わせて、視線を迷わせない | `theme.css` の `.rise` / `.rise-2〜4` |
| 六　静けさ | ビジネス系のページは動かさない。「視差効果を減らす」の人にはすべて止める | 読む人の判断を邪魔しない | `body[data-mode="business"]`、各所の `prefers-reduced-motion` |

## 速さの物差し

| 速さ | 使う場面 |
| --- | --- |
| 0.2–0.3 s | 触れたことへの反応（色・浮き上がり） |
| 0.7–1.1 s | 場面の移り変わり（門・入場・紋の描き起こし） |
| 1 s / 拍 | 心拍・稼働の印 |
| 90 s / 周 | 常に回るもの（光輪）。気づくか気づかないかの速さ |

## 守ること

- 新しい動きを足すときは、上の表のどの法則に当たるかを先に決める。当てはまらないなら入れない。
- `@keyframes` の名前はサイト全体で共有される。コンポーネント固有の動きには固有の名前を付ける（例：湯気は `steam-rise`）。
- 装飾は実装の段階で足してよい。ただし法則六（静けさ）を必ず守る。
